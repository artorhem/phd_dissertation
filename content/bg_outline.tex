\section{Computational Model}
	
Graph processing algorithms can be defined as matrix multiplications: $Y = X^TA$. Under this framing, we need to access $X^T$ and load in the relevant "rows" in $A$ (out or in-neighborhood) to produce the $Y$ vector (the value vector of cardinality $|V|$). $X^T$ can be placed in memory, since $|V|$ is of a manageable size.
	
In a single-node system, the computation model defines:
\begin{enumerate}
	\item \textbf{[IO]} is $A$ read in its entirety each time, or is there some reasonable way to access a subgraph, ideally only the neighborhood needed (all: naive linear algebra, whole matrix in a smart way: x-stream, only relevant edges: most systems). Does the system interleave IO with computation well enough to maximize the disk bandwidth utilization and the CPU cores well utilized?

	\item\textbf{[Consistency Semantics]} Is Y immediately visible? There can be a synchronization barrier at the end of a round of computation and only after that are the results of a round available for use in the next round(Most systems). Otherwise, the values can be immediately applied and no synchronization is needed (GraphChi) // What does this mean for a single-node system?
	
	\item\textbf{[Isolation Guarantees]} Is the matrix A mutable while a computation of Y is in progress? If it is, how does the system guarantee the correctness of results? If not, how are these read-only versions maintained, and how are multiple versions of the graph managed? What is the granularity at which these versions are maintained? What's the garbage collection schedule for cleaning up old versions that are no longer needed?
	
	In the context of an HTAP system: consistency and isolation semantics apply to both concurrent read/write transactional operations, and also to the concurrent running of analytics and transactional queries.

\end{enumerate}

The computational model influences and is influenced by the data layout; the workload ultimately decides what combination of the computation model and data layout will perform best.
These entities interact in non-trivial ways.
