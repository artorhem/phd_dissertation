\chapter{Lay Summary}

A lot of scientific and real world data encodes relationships between entities  and is often expressed as a graph.
As we produce ever larger graph datasets, there is a growing need to efficiently store and process them.
Traditionally, graph data is extracted from another data source (such as a database), transformed into a usable format for analysis, and loaded for analytics; this process must be repeated every time the data changes.
This thesis presents an intervention in this paradigm of extract-transform\slash{}preprocess-load by presenting a system to store the graph in an analytics-friendly format.
This approach cuts down the time and resources needed for the transformation and preprocessing steps, which ultimately brings down the cost of running analytics.
