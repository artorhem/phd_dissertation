\chapter{Preface}

This dissertation is original, unpublished, independent work by the author, Puneet Mehrotra.
The preliminary implementation of \project{} in Python was done by Natalie Ngan. The early prototype demonstrated the feasibility of storing arbitrary graph layouts in a key-value store.
All experiments in this thesis are based on a more performant C++ implementation of \project{} which was developed by the author in collaboration with Haotian Gong and Jack Li.
