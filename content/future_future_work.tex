\chapter{Future Work: Specialized Indexes on Graph Data}
\label{chap:specialized_indexing}

Most graph databases use indexes to speed up query processing.
There can be two types of special indexes that we would want to consider for future extensions of our work.
The first type of index allows the user to define a custom index on some higher-order graph structure such as triangles to which each vertex belongs.
Such indexes can significantly speed up graph mining queries that are related to clique mining, dense subgraph discovery, clustering, and other graph mining tasks.

The second type of index allows the user to define custom traversal patterns that are used to index the graph.
For example, a user might wish to access the vertices in a specific order, such as the Hilbert order, or based on some property of the vertices.

We believe that these two types of indexes can significantly speed up graph mining queries and are worth exploring in future work. Doing so would require exploring whether this is doable with the \wt{} indexing framework, and if so, how to implement it.
