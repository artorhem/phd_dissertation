\section{Evaluation}
\label{sec:evaluation}

We evaluate \project{} across four complementary settings.
We begin with property graph workloads (\autoref{sec:eval:property}), comparing \project{} to graph databases on graph algorithm benchmarks and LDBC SNB queries.
Next, we compare against specialized in-memory systems designed for rapid ingest of dynamic structural graphs (\autoref{sec:eval:dynamic}).
Finally, we evaluate against static structural graph processing systems, first in an out-of-core setting where the graph exceeds available memory (\autoref{sec:eval:ooc}), then fully in memory (\autoref{sec:eval:inmem}).
The systems to which we compare in each setting are described in \autoref{sec:related-work}.
For structural graph evaluations, we use the LDBC Graphalytics Benchmark kernels: BFS, PageRank (PR), connected components (CC), triangle counting (TC), and single-source shortest path (SSSP) ~\cite{LDBCGrapalytics22:online}.
We use a mix of \PM{microbenchmarks -- but we might remove these} and LDBC SNB queries to evaluate \project{} on property graphs.

%% --------------------------------------------------------------------------
\subsection{Experimental Setup and Datasets}
\label{sec:eval:setup}

We use two evaluation machines.
For all structural graph benchmarks, we use a dual-socket AMD EPYC 7643 Processor @ 2.30 GHz, 96 cores/192 threads, 2 TB of memory, and 2 TB NAND Flash SSD.
All benchmarks comparing \project{} to graph databases were run on an Intel Xeon W-2275 @ 3.30 GHz, 14 cores/28 threads, 128 GB RAM, 1 TB NVMe SSD.
Hyperthreading is enabled on both machines.

Both machines run Ubuntu 22.04 LTS with Linux 6.8.0, and all applications are compiled using GCC 13.3.0 with the optimization flags \texttt{-O3 -march=native -mtune=native}.

The Graphalytics benchmark suite provides a few reference datasets for evaluation, from which we selected the Graph500 graphs, DOTA League, Twitter MPI, and the friendster graphs.
We use the Koblenz Network Collection for the UK domain (uk2007) graph~\cite{kunegis2013konect}.
The uniform random graph datasets are generated with the graph generator developed by the Teseo authors~\cite{teseo2021deLeo}.
We repeat all experiments five times and report the mean.
%--------------------------------------------------------------------------
The out-of-core and in-memory analytics experiments (Sections \ref{sec:eval:ooc} and \ref{sec:eval:inmem}) use a static structural graph; \project{} opens read-only connections to a pre-loaded graph and performs no writes.
