\chapter{Preface}

\paragraph{Work intended for Publication:} A version of the work presented in this thesis has been submitted and is currently under review at the ACM SIGMOD/PODS International Conference on Management of Data under the title “Flexograph: Have your Graph OLTP and OLAP too”.

\paragraph{Research and Collaboration:} The idea for this dissertation is based on a research proposal developed by Prof. Seltzer to synthesize efficient data structures for persistent graph storage similar to work done by Idreos et al.~\cite{dataCalculator-StratosIdreos}.
However, this dissertation quickly branched away from that idea into developing a hybrid transactional and analytics graph database.

Puneet Mehrotra primarily implemented \project{}.
Haotian (Jack) Gong contributed code for topology cursors and led the effort to translate a few edge-centric algorithms to work with the \project{} API.
Generative AI assisted with property graph storage and query generation code and is documented as such in~\autoref{sec:eval:query-impl}.

Keith Bostic wrote a \wt{} patch that allows multi-threaded bulk insertions.
This is primarily a utility to accelerate the research and is not a contribution this thesis claims.

\paragraph{Use of Generative AI:} Generative AI tools assisted with code, test infrastructure, scripts, and figure generation.
Claude Opus 4.6~\cite{anthropic2026claudecodedocs} was used for this work and the author reviewed and verified all generated code, scripts, and results.
