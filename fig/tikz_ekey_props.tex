  \caption{Embedded vs.\ columnar property storage in the EdgeKey representation (Person vertices).
    \textbf{(a)}~Embedded mode appends the full property blob (145\,B for LDBC Person) after the degree bytes in each sentinel row; a degree update rewrites the entire value.
    \textbf{(b)}~Columnar mode keeps sentinel values compact (degrees only) and stores properties in per-label tables with \wt{} column groups.  Each column group is a separate B-tree, so scanning a single attribute (e.g., \texttt{creationDate}) reads only that group's pages.}
